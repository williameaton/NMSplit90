# NMSplit90

Author: Will Eaton \
Contact: weaton@princeton.edu

This respository hosts some F90 programs to compute normal mode splitting. 
Some of the original codewas translated from Jeroen Tromp's old F77 code, hence the emphasis
on '90'. 

The code framework relies on a number of external software or databases: 
- GLL mesh generated by [SPECFEM_GLOBE mesher](https://specfem3d-globe.readthedocs.io/en/latest/03_running_the_mesher/)
- [Coretran](https://github.com/leonfoks/coretran) library for KD tree features
- Hen Brett's [Fairhead suite](https://gitlab.com/hentheythem/fairhead) for joint VTI Trans MCMC inversions
- CUDA: originally this code was written with the [CUDA Fortran](https://developer.nvidia.com/cuda-fortran) API but has since been moved to [CUDA C++](https://docs.nvidia.com/cuda/cuda-c-programming-guide/) using bindings for greater control over device properties.
